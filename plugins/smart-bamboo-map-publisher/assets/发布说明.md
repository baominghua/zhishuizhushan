# 智慧竹山地图发布助手使用说明

1. 解压下载包，双击“启动地图发布助手.cmd”。不要只把单个脚本拖出文件夹运行。
2. 首次使用在“发布地址”中确认服务器、端口、用户、SSH 私钥、服务器素材根目录和平台路径根目录。
3. 选择素材根文件夹后点击“自动检索”。助手会识别正射 GeoTIFF、DSM、DTM、LAS/LAZ 点云以及 DJI B3DM/PNTS 3D Tiles。
4. 在清单中勾选本次要发布的项目。可使用清单上方的“全选”或“取消全选”快速切换，也可点击“手动添加文件”或“手动添加文件夹”。
5. 确认项目名。项目名决定服务器目录，允许中文、字母、数字、点、下划线和短横线。
6. 点击“发布已勾选项”。大文件会使用 SFTP 续传；目录型成果先无压缩打包，再上传、校验并原子切换。
7. 发布成功的行会在最右侧显示“查看并复制”。点击后可查看完整平台路径，并自动复制到剪贴板。
8. 也可使用窗口底部的“复制发布路径”，一次复制当前批次的全部成功路径，再到“影像成果 → 上传并自动匹配 → 服务器 / NAS 目录”进行登记。

## 分类说明

- 正射影像：`result.tif`、`orthophoto.tif` 或可见光目录中的 TIFF。
- DSM：`dsm.tif`，包含树木和建筑等表面高度。
- DTM：`dtm.tif` 或 DEM/DTM 命名的地形文件。
- B3DM：倾斜摄影实景网格。
- PNTS：点云瓦片。与 B3DM 分开发布，不会互相覆盖。
- LAS/LAZ：原始点云任务目录，可发布到服务器后再在平台登记转换。

## 常见问题

- 页面上传大文件不动：改用本助手，失败后对同一项再次发布即可续传。
- 服务器已存在同名成果：原成果自动移入 `.releases` 备份后再切换。
- 找不到素材：确认文件不是隐藏临时目录，并使用“手动添加”。
- SSH 失败：确认 Windows 已安装 OpenSSH 客户端、私钥路径正确且公钥已配置在服务器。
- 发布完成不等于已上图：还需把输出的平台路径登记到影像管理；平台会继续做范围识别和林班关联。

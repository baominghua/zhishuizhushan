# 智慧竹山 V2 范围基线

## 1. 建设目标

V2 以首期 20 万亩示范范围为正式建设边界，形成可扩展到 200 万亩及全市范围的数据与业务架构。首期目标不是一次实现规格书全部远景功能，而是完成资源一张图、巡护管护、采伐监管和安全事件四条可投入使用的核心能力。

## 2. 范围分级

| 优先级 | 范围 | V2 首期结果 |
| --- | --- | --- |
| P0 | 统一身份、组织、权限、数据范围、行政区划、字典、文件、消息、审计 | 正式生产底座 |
| P0 | 林班/小班、林权、资源调查、影像、道路、图层、批量导入 | 20 万亩一张图 |
| P0 | 统一任务、事件、待办、通知、附件和操作记录 | 跨模块业务主线 |
| P1 | 巡护计划、任务、轨迹、问题上报、处置和验收 | 巡护闭环 |
| P1 | 采伐申请、限额、审批、作业监管、验收和追溯 | 采伐闭环 |
| P1 | 移动端离线任务、定位轨迹、照片视频、同步 | 现场作业 MVP |
| P2 | 班组、人员、合同、考勤、工资和培训 | 劳务管理闭环 |
| P2 | 安全帽、SOS、跌倒、脱帽、越界、设备运维 | 安全应急闭环 |
| P2 | 无人机、飞手、航线、飞行任务和成果 | 低空作业闭环 |
| P3 | AI 数据集、模型版本、部署、推理和评测 | 六类模型分批接入 |
| P3 | 领导驾驶舱、碳汇、产业经济、数字孪生 | 数据成熟后上线 |

## 3. 首期必须交付

### 3.1 平台底座

- 账号、组织、岗位、角色、菜单、按钮和数据范围权限。
- 统一待办中心、消息中心、事件中心、附件中心和审计中心。
- 数据字典、编码规则、行政区划、系统参数和接口凭证管理。
- 健康检查、日志、监控、备份恢复和双机容灾运行手册。

### 3.2 空间资源

- 林班和小班独立层级，支持空间版本、资源调查版本和变更记录。
- 林权档案与林班/小班关联，但不把法律档案字段写入空间主表。
- KMZ、OVKML、OVOBJ、GeoJSON、Shapefile、CSV、XLSX 批量导入。
- 导入采用“上传解析 → 异常确认 → 正式入库”，无异常批次允许一键完成。
- 影像、道路、经营主体、作业任务和风险事件均可关联空间单元。
- 百万亩级分层聚合、矢量瓦片、视口加载和空间筛选。

### 3.3 业务闭环

- 巡护：计划、任务、接单、轨迹、上报、处置、复核、归档。
- 采伐：申请、额度校验、审批、作业计划、围栏监管、完工验收、资源更新。
- 安全：告警接入、事件分级、派单、处置、升级、关闭和复盘。
- 所有闭环统一显示当前责任人、办理时限、证据、状态和时间轴。

## 4. 首期明确不做

- 不承诺 20 万亩全部达到 LOD3 和 10cm 三维精度，只建设代表性示范区。
- 不一次性训练并验收全部六个云端模型和四个边缘模型。
- 不建设自动双活切换，当前维持主节点加只读热备和人工切换。
- 不在 50Mbps 公网条件下承诺 100 路 1080P 实时视频并发。
- 不在软件项目中包办遥感测绘、模型标注、设备固件和通信专网等外部生产工作。
- 不把交易金融、全量碳汇、模型市场和全市数字孪生作为 V2.0 上线门槛。

## 5. 责任边界

| 工作包 | 交付责任 |
| --- | --- |
| 软件平台 | 页面、接口、流程、权限、数据管理、监控和部署 |
| 数据生产 | 林班边界、影像、点云、道路、权属整理、质量报告 |
| AI 模型 | 样本、标注规范、训练、测试集、指标报告、推理包 |
| 硬件接入 | 设备、协议、SDK、固件、测试账号、现场联调 |
| 基础设施 | 云主机、对象存储、带宽、短信、地图密钥和安全服务 |

## 6. 变更控制

新增需求必须注明所属阶段、业务价值、依赖数据、依赖设备、验收口径和对工期的影响。未进入本范围基线的功能不得直接加入当期开发队列；紧急需求由产品、业务、技术和项目负责人共同评审。

# 智慧竹山 V2 路线图、任务书与验收方案

## 1. 总体周期

建议以 2 周为一个迭代，整体按照 9 至 12 个月规划。以下工期以 12 至 18 人稳定团队、数据和设备接口按时提供为前提；第三方数据生产和 AI 训练延期将直接影响对应阶段。

## 2. 阶段计划

| 阶段 | 周期 | 核心交付 | 上线门槛 |
| --- | --- | --- | --- |
| V2.0 方案与底座 | 3 周 | 范围、原型、领域模型、数据标准、技术底座 | 基线评审通过 |
| V2.1 资源一张图 | 8–10 周 | PostGIS、林班小班、林权、影像、导入、质量、瓦片 | 20 万亩真实数据可用 |
| V2.2 巡护与采伐 | 8–10 周 | 任务事件、巡护闭环、采伐闭环、移动离线 MVP | 两条现场流程跑通 |
| V2.3 劳务与安全 | 10–12 周 | 班组人员、合同考勤、安全帽、告警、应急 | 设备和安全演练通过 |
| V2.4 无人机与 AI | 10–12 周 | 低空任务、成果自动归档、模型管理、首批模型 | 供应商与模型专项验收 |
| V2.5 驾驶舱与扩展 | 6–8 周 | 专题驾驶舱、示范区孪生、碳汇和产业接口 | 数据口径和性能验收 |

### 2026-09-02 道路空间台账闭环

- 新增林区道路正式主档：道路编号、等级、路面、路况、宽度、长度、责任单位、最近巡检和备注均进入专用接口与台账，不以通用表单替代。
- 道路空间必须使用有效 LineString/MultiLineString，并至少关联一个同县正式林班；系统按真实线段自动测算公里数并沿林班关系执行数据范围权限。
- 道路支持新增、编辑、软删除、恢复、巡检维修流水和 CSV 导出，维修记录可回写最近巡检日期与处置后路况。
- GIS 一张图增加独立林区道路图层；二维与三维均使用高对比琥珀色贴线/贴地显示，差路况和封闭路况分别以橙色、红色提示。

## 5. 验收结构

V2 不再以“所有功能 100% 完成”作为单一验收描述。每个阶段分别验收以下五类成果：

| 验收包 | 核心证据 |
| --- | --- |
| 软件功能 | 用户故事、状态流、页面、接口、权限、自动化测试 |
| 数据生产 | 数据目录、质量报告、坐标系、数量、面积、抽样结果 |
| AI 模型 | 冻结测试集、准确率、召回率、时延、版本和复核记录 |
| 硬件设备 | 协议、模拟器、实机、掉线重连、告警、升级和故障记录 |
| 性能安全 | 压测、弱网、备份恢复、容灾、漏洞扫描、等保材料 |

## 6. 首期验收指标

### 6.1 数据与 GIS

- 20 万亩范围可按区县、乡镇、村、林班和小班分层查询。
- 林班/小班编号唯一、几何有效，林权关系无孤儿记录。
- 常用 GIS 首屏在目标网络下不超过 3 秒，平移缩放不请求全量图斑。
- 导入任务支持断点和后台执行，浏览器关闭后仍可查询进度。
- 无异常文件可一键正式入库，有异常文件能定位到具体记录和图斑。

### 6.2 业务闭环

- 巡护任务可以完成计划、派发、接单、轨迹、上报、处置、复核和归档。
- 采伐业务可以完成申请、额度校验、审批、作业、围栏告警、验收和资源更新。
- 每条任务和事件都可追溯责任人、时限、证据、状态变化和最终结果。
- 不同角色只能查看和办理其菜单、操作和数据范围允许的内容。

### 6.3 移动与弱网

- 在 2G 或无网条件下可以查看已下载任务、记录轨迹和填写现场报告。
- 网络恢复后可继续上传，重复提交不产生重复业务记录。
- 大照片和视频支持压缩、分片、重试和上传进度。

### 6.4 运行与安全

- 核心 API 达到约定响应时间，1000 并发用户和 500 QPS 通过专项压测后方可写入最终指标。
- 所有生产秘密不进入 Git，数据库和管理端口不向公网开放。
- 完成一次数据库恢复、对象文件恢复和人工容灾演练。
- 审计日志至少保留 6 个月，并可按用户、对象、动作和时间查询。

## 7. 发布门禁

每个版本必须通过：代码评审、单元测试、接口契约测试、数据库迁移测试、权限测试、关键流程端到端测试、浏览器视觉检查、性能基线和回滚演练。任一核心数据校验失败、存在默认密码、接口返回演示数据或无法回滚时不得上线。

## 8. 关键风险

| 风险 | 影响 | 控制措施 |
| --- | --- | --- |
| 需求将远景全部压入首期 | 工期和质量失控 | 以本范围基线和阶段验收为准 |
| 林班、林权和主体编码不统一 | 无法关联和统计 | V2.0 冻结编码及迁移映射 |
| 测绘数据质量不稳定 | 地图、面积和审批错误 | 自动质检加业务抽检，不合格隔离 |
| AI 缺少真实标注数据 | 指标无法达成 | 模型与平台分开验收，先建数据闭环 |
| 设备协议或样机延迟 | 安全和 IoT 模块延期 | 先提供模拟器，合同约束接口交付 |
| 50Mbps 带宽承载视频 | 卡顿和不可用 | 视频专项带宽、边缘接入和并发控制 |
| 双机人工容灾达不到 99.9% | SLA 不成立 | 托管高可用数据库或增加第三节点 |
| 通用表单继续承载核心交易 | 数据失控、难审计 | 核心流程必须使用专用表和状态机 |

# 毛竹无人机影像资源试算研究底稿

更新日期：2026-08-26

## 结论

现有 2.2–3.4 cm RGB 正射影像足以支持毛竹冠层覆盖率与竹冠等价数量的科研试算；LAS 具备 RGB、强度、GPS 时间和多回波，适合作为后续冠层高度与垂直结构证据。当前数据不能直接生成法定或经营结算口径的毛竹蓄积量（m³），原因是 DJI LAS 的分类码尚未区分地面与植被，且 RGB 无法可靠反演胸径、竹壁厚和竹秆形数。平台首版应保存“资源株数 + 密度 + 冠层覆盖 + 地上生物量”的试算值和区间，正式蓄积量待本地样地标定。

## 本地数据盘点

- `D:\数据迁移` 共 16 个项目目录。
- 44 个 GeoTIFF，约 11.45 GB；主要正射分辨率约 0.022–0.034 m，DSM 分辨率约 0.044–0.068 m。
- 236 个 LAS，约 117.02 GB；格式为 LAS 1.4 Point Format 7。
- 逐项目抽取首个 LAS 的 100 万点：分类码均为 0；具有 RGB、Intensity、GpsTime、ReturnNumber/NumberOfReturns 等维度，最多观察到 8–10 次回波。
- 结论：多回波和强度字段可用，但必须先运行 SMRF/CSF 等地面分类并生成 DTM/CHM，不能直接用绝对 Z 高程当竹高。

## 首版模型

1. 根据林班 WGS84 边界裁切匹配的最新正射 COG。
2. 将大图降采样到最多 1600×1600 分析窗口，保留原始分辨率、分析分辨率和有效像素数量。
3. 使用归一化绿色优势指数与 Otsu 阈值分割冠层。
4. 在约 2.2 m 空间邻域内提取纹理峰值，生成“竹冠等价数量”；该指标不是逐株人工判读结果。
5. 按林班面积换算株/亩，输出 ±28% 的保守区间。
6. 若林班已有正式平均胸径，使用研究异速生长方程计算 AGB；否则采用 8.9 cm 科研先验，并显著扩大区间、降低置信度。
7. 同区域点云仅登记为结构证据。分类码未区分地面/植被时，不生成归一化竹高。
8. 结果写入 `yieldEstimate.mosoInventory`，旧结果进入最多 12 期历史；不覆盖正式 `standingDensity`、`avgDbhCm`、`avgHeightM` 等调查字段。

## 本地标定门槛

- 至少选择 20–30 个覆盖密度、坡位和经营强度的样地。
- 每个样地记录边界、毛竹株数、胸径分布、代表性竹高和样地蓄积/生物量口径。
- 点云运行地面分类，生成 DTM、DSM 和 CHM；抽样检查坡地、道路和林窗误分。
- 对 RGB 竹冠结果人工标注不少于 1,000 个冠幅实例，按地块分组训练/验证，禁止同一航带随机泄漏到训练和验证两侧。
- 本地验收建议：株数密度相对 RMSE ≤15%，冠层覆盖绝对误差 ≤5 个百分点；蓄积量须另设样地材积表和误差门槛。

## 风险与边界

- 季节、叶色、阴影、混交阔叶树与正射拼接缝会影响 RGB 分割。
- 竹冠存在遮挡和重叠，竹冠等价数不等同于可采伐成竹数。
- 毛竹为空心竹秆；胸径、竹壁厚、竹秆形数缺一时，以 m³ 表示“正式蓄积量”会产生虚假精度。
- 任何试算值必须保留影像场景、拍摄日期、模型版本、阈值、置信度和人工复核状态。

# 智慧竹山 V2 核心原型说明

## 1. 原型目标

本原型验证 V2.0 的信息架构和五个高频工作流，不连接正式数据库、不替换现有生产页面。原型中的业务记录均明确标注为交互样例。

## 2. 设计基线

- 延续 V1 浅色政务后台和克制绿色品牌识别。
- 工作台先展示待办和风险，不展示技术连接参数、权限头或数据库类型。
- 地图占据 GIS 页面主要空间，筛选默认收起并从顶部展开。
- 台账和办理分离；详情、办理和历史记录按需展开。
- 普通用户只看当前业务动作，系统审计进入详情时间轴。
- 所有长任务可离开页面，重新进入后继续查看进度。

## 3. 五套页面

### 3.1 我的工作台

用户进入系统后先看到个人待办、紧急事件、今日任务和空间态势。待办支持按业务域切换并直接进入办理页。领导和技术人员看到的内容由角色工作台配置决定。

### 3.2 GIS 一张图

地图顶部提供全局搜索、行政区定位、筛选、图层和地图工具。筛选默认收起，已生效条件以标签展示。点选林班后展示资源摘要，并可继续查看林权、任务、事件和影像。

### 3.3 数据接入

流程固定为“上传文件 → 自动解析 → 只确认异常 → 正式入库”。无异常文件不再要求重复审核；系统自动生成导入报告和审计记录。

### 3.4 巡护办理

管理人员查看和分派任务，一线人员接单、导航、记录轨迹、上报问题并提交结果。复核人员只处理待复核任务。轨迹、照片和问题点位统一作为证据。

### 3.5 采伐办理

申请人选择经营主体、林权档案和林班/小班，系统自动检查面积与额度。审批人员处理资料和空间范围，作业人员查看围栏和时间窗，验收后生成批次并更新资源版本。

## 4. 核心交互

| 交互 | 原型行为 |
| --- | --- |
| 左侧导航 | 无刷新切换五个工作区 |
| 待办行 | 跳转到对应办理页面并选中记录 |
| 地图筛选 | 顶部按钮展开/收起，条件形成标签 |
| 地图对象 | 点击点位或图斑打开右侧详情 |
| 文件上传 | 读取文件名和大小并进入解析状态 |
| 异常处理 | 仅显示异常项，确认后允许正式入库 |
| 巡护办理 | 接单、开始、上报、提交改变任务状态 |
| 采伐办理 | 不同状态只显示当前可执行动作 |
| 空间关联 | 使用搜索选择器选择已有林班，不自由输入编号 |

## 5. 响应式

- 桌面端使用固定侧栏和宽内容区。
- 平板端收窄侧栏并让工作台、列表和详情重新排列。
- 手机端使用顶部导航抽屉；地图、详情和筛选互斥显示，业务表格转为列表。

## 6. 原型入口

`v2-prototype.html`

默认进入“我的工作台”，URL 哈希分别为：

- `#workspace`
- `#map`
- `#imports`
- `#patrol`
- `#harvest`
